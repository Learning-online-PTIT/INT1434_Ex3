MINISHOP - Hiệu sách của Dread (Buổi 3: PHP + MySQL)

Cách chạy (XAMPP):
1. Chép thư mục minishop vào C:\xampp\htdocs\
2. Mở phpMyAdmin -> Import -> chọn file minishop.sql (nằm cùng cấp với thư mục minishop).
3. Kiểm tra includes/db.php (mặc định: user root, mật khẩu rỗng).
4. Mở http://localhost/minishop/

Bài tập về nhà:
1. Sắp xếp theo giá : index.php?sort=price_asc | index.php?sort=price_desc
2. Đếm kết quả      : dòng "Tìm thấy N sản phẩm" trên trang chủ
3. Cùng danh mục    : cuối product.php?id=N (tối đa 3 sản phẩm)
4. Sao lưu          : minishop.sql
